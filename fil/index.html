PeriDoc: HWP PDF Office Viewer

Buksan ang HWP, PDF at Office file kahit offline. Mabilis, magaan at pribado.

Google Play

Ang PeriDoc ay mabilis, libre at ligtas na document viewer para sa Android. Buksan ang mga HWP, HWPX, PDF, Word (DOCX), Excel (XLSX) at PowerPoint (PPTX) file mismo sa iyong phone o tablet. Hindi kailangan ng account, at hindi kailanman ina-upload ang iyong mga file.

HWP at HWPX viewer

Kailangan mo bang buksan ang HWP file mula sa paaralan, kumpanya o opisina ng gobyerno sa Korea? Binubuksan ng PeriDoc ang mga dokumento ng Hangul word processor (HWP, HWPX, HWP 3.0, HML) na ginawa sa Hancom Office, at napapanatili ang mga table, larawan at layout ng pahina. May kasama nang Korean fonts kaya tama ang hitsura ng teksto, at puwede mo ring i-import ang sarili mong PC fonts para mas malapit sa orihinal.

PDF reader

Magbasa ng PDF nang maayos, may suporta para sa paghahanap ng teksto, pagpili at pagkopya, table of contents, page thumbnails at PDF na may password.

Office document viewer

Madaling tingnan ang mga Word document (DOCX), Excel spreadsheet (XLSX) at PowerPoint presentation (PPTX) nang hindi nag-i-install ng mabibigat na office suite.

Maghanap sa loob ng iyong mga dokumento (may OCR)

Hanapin ang teksto sa loob ng iyong mga dokumento, hindi lang ang pangalan ng file. Ini-index ng PeriDoc ang mga file sa iyong device kaya agad na ipinapakita ng paghahanap kung aling file at pahina ang may tugma. Ang teksto sa mga na-scan na PDF at larawan ay kinikilala sa device lang (OCR) at isinasama sa iyong mga resulta.

Smart search (opsyonal)

Hindi maalala ang eksaktong salita? Nauunawaan ng smart search ang konteksto at kahulugan para mahanap ang mga kaugnay na dokumento at eksena sa iyong mga larawan. I-download ang model nang isang beses (humigit-kumulang 388 MB), at mula noon, nananatili sa iyong device ang lahat ng pagproseso nang walang internet.

Optimized para sa foldable at tablet

Hawakan nang naka-landscape ang Galaxy Tab o nakabukas na Galaxy Fold para makita nang magkatabi ang listahan ng file at ang dokumento. Sa Flex mode (kalahating nakatiklop), nananatili ang dokumento sa itaas na kalahati at nasa ibaba ang mga page control para mas madaling gamitin. Suportado ang mga keyboard shortcut (gaya ng Ctrl+F) at pag-scroll gamit ang mouse wheel.

Iba pang suportadong uri ng file

Text (TXT), Markdown (MD), CSV, HTML at mga larawan (JPG, PNG, WebP, HEIC, GIF, BMP).

Mga feature

  • Isang pahina o tuloy-tuloy na pag-scroll, dalawang pahinang magkatabi kapag naka-landscape, pinch para mag-zoom
  • Maghanap sa loob ng dokumento, pumili at kumopya ng teksto, kopyahin ang mga table bilang CSV
  • Madaling lumipat gamit ang table of contents at page thumbnails, at ituloy ang pagbabasa kung saan ka huminto
  • Mga kamakailang paghahanap, makita nang sabay-sabay ang lahat ng tugma sa isang dokumento, at shortcut sa icon ng app para sa mabilis na paghahanap
  • I-rotate ang pahina, i-save ang pahina bilang larawan, i-save bilang PDF, i-share o buksan sa ibang app
  • Built-in na file manager para mahanap ang bawat dokumento sa iyong device, may Basurahan at home screen shortcuts
  • Gawing default app para agad mabuksan ang mga attachment mula sa Gmail, messenger, Downloads at file manager
  • Built-in na Korean fonts at puwedeng mag-import ng sarili mong PC fonts

Pribado at offline

  • Hindi kailanman ina-upload o ipinapadala ng PeriDoc ang mga dokumento mo kahit saan, at walang network access ang bahaging nagpapakita ng iyong mga dokumento.
  • Ang pag-index, pagkilala ng teksto (OCR) at smart search ay tumatakbo lang sa iyong device nang hindi nagpapadala ng data kahit saan.
  • Nabubuksan ang mga dokumento kahit offline. Walang sign-up, walang login.
  • Ginagamit lang ang internet para sa maliit na banner ad sa ibaba ng screen (Google AdMob) at sa pag-download ng smart search model.
