PeriDoc: Baca HWP, PDF, Office

Buka HWP, PDF, Word, Excel, dan PowerPoint offline. Cepat, ringan, dan privat.

Google Play

PeriDoc adalah aplikasi pembaca dokumen yang cepat, gratis, dan aman untuk Android. Buka file HWP, HWPX, PDF, Word (DOCX), Excel (XLSX), dan PowerPoint (PPTX) langsung di ponsel atau tablet Anda. Tanpa akun, dan file Anda tidak pernah diunggah.

Pembaca HWP dan HWPX

PeriDoc membuka dokumen pengolah kata Hangul (HWP, HWPX, HWP 3.0, HML) yang dibuat dengan Hancom Office, lengkap dengan tabel, gambar, dan tata letak halamannya. Font Korea sudah tersedia di dalam aplikasi sehingga teks tampil dengan benar, dan Anda bisa mengimpor font dari PC sendiri agar tampilannya makin mendekati aslinya.

Pembaca PDF

Baca file PDF dengan pencarian teks, pemilihan dan penyalinan teks, daftar isi, thumbnail halaman, serta dukungan PDF yang dilindungi kata sandi.

Penampil dokumen Office

Lihat dokumen Word (DOCX), spreadsheet Excel (XLSX), dan presentasi PowerPoint (PPTX) tanpa perlu memasang paket aplikasi perkantoran.

Cari di dalam dokumen (dengan OCR)

Temukan teks di dalam dokumen, bukan hanya nama file. PeriDoc mengindeks file di perangkat Anda sehingga hasil pencarian langsung menunjukkan file dan halaman yang memuat kata tersebut. Teks dalam PDF hasil pindaian dan foto dikenali hanya di perangkat (OCR) dan ikut masuk ke hasil pencarian.

Pencarian cerdas (opsional)

Pencarian cerdas memahami konteks dan makna untuk menemukan dokumen terkait dan adegan dalam foto Anda. Cukup unduh modelnya sekali (sekitar 388 MB), dan selanjutnya semua pemrosesan tetap di perangkat Anda tanpa internet.

Kartu tenggat

Buka pengumuman, dan PeriDoc menemukan tanggal berlabel seperti masa pendaftaran, tenggat, dan waktu acara, lalu menampilkannya di atas dokumen dengan hitung mundur. Ketuk untuk menambahkannya ke kalender atau menelepon nomor kontak. Mendukung tanggal dalam dokumen berbahasa Korea dan Inggris.

Telusuri dengan gambar (dengan pencarian cerdas)

Gunakan satu gambar untuk menemukan gambar yang mirip, atau foto halaman cetak untuk menemukan file aslinya di perangkat Anda.

Perbandingan versi dan pembersihan duplikat

PeriDoc mengelompokkan versi dokumen yang sama, seperti "laporan_final" dan "laporan_v2", dan menandai bagian yang diubah, ditambah, atau dihapus di antara dua versi langsung di halaman. Di layar lebar, lihat kedua versi berdampingan. Temukan file yang identik dan pindahkan salinan lebihnya ke Sampah.

Dioptimalkan untuk perangkat lipat dan tablet

Dalam posisi mendatar, Galaxy Tab atau Galaxy Fold yang terbuka menampilkan daftar file dan dokumen berdampingan. Dalam Mode Flex (setengah terlipat), dokumen ada di atas dan kontrol halaman di bawah. Pintasan keyboard (seperti Ctrl+F) dan roda mouse didukung.

Jenis file lainnya

Teks (TXT), Markdown (MD), CSV, HTML, dan gambar (JPG, PNG, WebP, HEIC, GIF, BMP).

Fitur

  • Tampilan satu halaman atau gulir bersambung, dua halaman berdampingan saat layar mendatar, cubit untuk zoom
  • Salin tabel sebagai CSV
  • Lanjutkan membaca dari bagian terakhir
  • Pencarian terbaru, lihat semua hasil yang cocok dalam satu dokumen sekaligus, dan cari cepat lewat pintasan ikon aplikasi
  • Putar halaman, simpan halaman sebagai gambar, simpan sebagai PDF, bagikan, atau buka di aplikasi lain
  • Pengelola file bawaan yang menemukan semua dokumen di perangkat Anda, dengan Sampah dan pintasan layar utama
  • Jadikan aplikasi default untuk langsung membuka lampiran dari Gmail, aplikasi pesan, Unduhan, dan pengelola file

Privat dan offline

  • PeriDoc tidak pernah mengunggah dokumen Anda atau mengirimnya ke mana pun, dan area yang menampilkan isi dokumen Anda tidak memiliki akses jaringan.
  • Pengindeksan, pengenalan teks (OCR), pencarian cerdas, kartu tenggat, dan perbandingan versi semuanya berjalan hanya di perangkat Anda tanpa mengirim data ke mana pun.
  • Membuka dokumen secara offline. Tanpa pendaftaran, tanpa login.
  • Internet hanya digunakan untuk iklan banner kecil di bagian bawah layar (Google AdMob) dan untuk mengunduh model pencarian cerdas.
